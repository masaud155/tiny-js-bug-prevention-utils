required

Verify a value is present and avoid missing-value failures.

Prevents missing values

This helper throws when the value is null or undefined.

required(value, 'value')

isPlainObject

Confirm the input is a plain object, not an array or null.

Prevents unsafe object assumptions

Supports JSON input like objects, arrays, strings, and null.

isPlainObject(value)

hasOwn

Check whether an object owns a property without inherited keys.

Prevents prototype property mistakes

Enter an object JSON and a property name to test ownership.

hasOwn(object, key)

toArray

Normalize null, single values, and arrays into a consistent array.

Prevents list handling errors

Try values like null, "tag", or ["js","react"].

toArray(value)

safeJsonParse

Parse JSON safely and return fallback when parsing fails.

Prevents JSON parse crashes

Try valid JSON or invalid strings like {hello:}

safeJsonParse(jsonString, null)

assertFiniteNumber

Validate that a value is a real finite number.

Prevents NaN and Infinity bugs

Enter numbers like 42, 0.5, or invalid values like Infinity.

assertFiniteNumber(number, 'number')

withTimeout

Wrap a promise so it rejects if it takes too long.

Prevents hanging async flows

Select delay and timeout values to see success or failure.

withTimeout(promise, timeoutMs)

assertOneOf

Check that a value matches one of the allowed options.

Prevents unknown state values

Allowed values: pending, paid, failed.

assertOneOf(value, options, 'status')
